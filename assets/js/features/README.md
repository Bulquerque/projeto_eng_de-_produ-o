# Features JS

Este diretório concentra os entrypoints canônicos do runtime por fase.

Mapa atual:

- `phase-1/` -> Validação inicial
- `phase-2/` -> Baseline
- `phase-3/` -> Cenários
- `phase-4/` -> Score e otimização
- `phase-5/` -> Entrega final

Os módulos legados continuam em `assets/js/phase2/` a `assets/js/phase5/` para compatibilidade e podem ser migrados gradualmente.
