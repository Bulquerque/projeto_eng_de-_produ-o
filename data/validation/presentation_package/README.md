# Pacote de apresentação

Este ZIP reúne prints do otimizador para as duas empresas nas reformas de 2027 e 2033.

Ordem sugerida:

1. `01_empresa1_reform_2027_custo_controlado.png` - Empresa 1 / 2027 (CBS plena) / Custo controlado
2. `02_empresa1_reform_2027_mais_alcance.png` - Empresa 1 / 2027 (CBS plena) / Mais alcance
3. `03_empresa1_reform_2033_custo_controlado.png` - Empresa 1 / 2033 (Regime pleno) / Custo controlado
4. `04_empresa1_reform_2033_mais_alcance.png` - Empresa 1 / 2033 (Regime pleno) / Mais alcance
5. `05_empresa2_reform_2027_custo_controlado.png` - Empresa 2 / 2027 (CBS plena) / Custo controlado
6. `06_empresa2_reform_2027_mais_alcance.png` - Empresa 2 / 2027 (CBS plena) / Mais alcance
7. `07_empresa2_reform_2033_custo_controlado.png` - Empresa 2 / 2033 (Regime pleno) / Custo controlado
8. `08_empresa2_reform_2033_mais_alcance.png` - Empresa 2 / 2033 (Regime pleno) / Mais alcance

Leitura executiva:

- **Custo controlado**: solução mais próxima de um otimizador clássico orientado a custo.
- **Mais alcance**: ajuste dos pesos para valorizar qualidade de serviço e robustez, aceitando um custo um pouco maior quando a fronteira de trade-off compensa.
