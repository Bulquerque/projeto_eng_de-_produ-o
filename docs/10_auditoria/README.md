# Auditoria e rastreabilidade

Esta pasta reúne o diagnóstico, a matriz de correções, os resultados canônicos e os registros das duas auditorias finais do projeto.

Os números publicados devem ser lidos junto com `resultados-canonicos.md`. O relatório revisado distingue baseline estrutural, baseline comparável por regime tributário, dados observados, valores calculados, parâmetros, proxies e fallbacks.

As auditorias protegidas exigem a variável `VISAGIO_DATA_PASSWORD`. A credencial não é armazenada no repositório nem nos artefatos.
